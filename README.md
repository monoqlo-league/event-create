# MONOQLO チーム表作成

MONOQLO麻雀部 チーム戦(イベント戦)の「チーム表」を作るページ(`index.html`)を置くリポジトリ。
チーム名とメンバーを画面で登録し、ランキングページ(event-ranking)が読み込むCSVを出力する。

## 用意するもの

雀魂の大会管理画面から書き出した **参加者リストのCSV**(`プレイヤー名,id,備考`)。メンバーはこのリストから選ぶため、必ず要る。

## 使い方

1. **大会の設定**: 大会名・開始年・開始月・枝番・チーム数・チーム人数・リーグ数を入力し、参加者リストのCSVを読み込んで、「次へ」を押す。
2. **チームの登録**: チームごとにチーム名を入力し、メンバーをプルダウンから選ぶ。選ぶとIDが左に表示される。各チームのいちばん上の枠が **リーダー**。
3. 「CSVを出力」を押すと、CSVファイルが保存される。
4. 保存されたCSVを、データ用リポジトリ **event-data** にアップロードする。

### リーグ数(予選・セミファイナル・ファイナルなど)

- リーグが1つだけの大会は、リーグ数を `1` のままにする。
- リーグ数を2以上にすると、リーグごとの設定が出る。予選・セミファイナル・ファイナルなら `3`。
- **リーグ名**: 初期値が入る(3なら 予選・セミファイナル・ファイナル)。書き換えられる。「:」「/」は使えない。
- **チーム数**: 2次以降は、そのリーグに進めるチーム数を入れる。前のリーグより少なく、4以上(麻雀は4チーム必要)。
- **PTの持ち越し**: 2次以降のリーグを、前のリーグのPTをどれだけ引き継いで始めるか。持ち越さない・半分・全部から選ぶ。
- 進出するチームは、ランキングページが前のリーグの上位から自動で決める。

### 入力のルール

- 参加者リストの人数が「チーム数×チーム人数」より少ないと、次のページへ進めない。
- プルダウンは名前順。ほかの枠で選んだ参加者はグレー表示になり、選べない。選び直すか「選択」に戻すと、また選べるようになる。
- チーム名は必須。同じチーム名は使えない。
- メンバーの枠は、すべて選ぶ。未選択が1つでもあると出力できない。
- ページの下に、未選択の枠の数と、まだどのチームにも入っていない参加者が表示される。
- 入力内容と参加者リストは、そのブラウザに自動で残る。ページを閉じても続きから入力できる。最初からやり直すときは、1ページ目の「入力内容をすべて消す」を使う。
- 参加者リストを別のCSVに差し替えたとき、新しいリストに居ない人を選んでいた枠は未選択に戻る。

## 出力するCSV

```
大会名,チーム名,プレイヤー名,プレイヤーID,役割,リーグ構成
MONOQLO麻雀イベント戦,ネコババしちゃ,ここここきじゅ,137746445,リーダー,予選:12/セミファイナル:6:50/ファイナル:4:0
MONOQLO麻雀イベント戦,ネコババしちゃ,綴美,132889350,,予選:12/セミファイナル:6:50/ファイナル:4:0
```

- 「役割」の列は、各チームのいちばん上の枠で選んだメンバーに `リーダー` と入る。ほかのメンバーは空欄。
- 「リーグ構成」の列は、全行に同じ値が入る。`リーグ名:チーム数:持ち越しの%` を「/」でつないだもの。リーグが1つだけなら `本戦:12` のようになる。

- 文字コードは UTF-8(BOM付き)。Excelでそのまま開ける。
- ファイル名は、1ページ目の入力から自動で決まる。**開始年4桁+開始月2桁+枝番2桁.csv**(例: 2026年10月の1つ目の大会は `20261001.csv`)。
- 枝番は、同じ年月に大会が複数あるときの通し番号。初期値は `01`。
- 同じ大会の対局記録(雀魂の牌譜履歴)は、event-data に `開始年月枝番-games1.csv`(例: `20261001-games1.csv`)の名前で置く。リーグが1つだけでも `-games1.csv`。2次リーグは `-games2.csv`、以降も同じ。
